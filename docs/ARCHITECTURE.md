# معمارية EduAssist V2

## الحالة

هذه الوثيقة تلخص الوضع المعماري الحالي. سجل القرارات المعمارية في `docs/adr/`
هو المرجع لأي استثناء أو تغيير تفصيلي.

## حدود النظام

- الواجهة الأمامية: نكست جي إس (Next.js).
- الواجهة الخلفية: فاست أي بي (FastAPI) مع لانغ غراف (LangGraph).
- التخزين: بوستغرس (PostgreSQL)، ويشمل بيانات التطبيق ونقاط تفتيش الرسم.

## تدفق المحادثة

1. تصادق الواجهة عبر جلسة محفوظة في بوستغرس (PostgreSQL).
2. تفتح قناة مقبس الويب (WebSocket) للمحادثة المملوكة للمستخدم.
3. ترسل رسالة المستخدم عبر HTTP دون تمرير معرف المستخدم.
4. تتحقق خدمة المحادثة من الاتصال والملكية وتحجز التشغيل وتحفظ الرسالة، ثم يرد HTTP فورًا بالحالة 202.
5. يشغّل لانغ غراف (LangGraph) مسار البث الوحيد عبر `astream_events` في مهمة خلفية بجلسة قاعدة بيانات مستقلة.
6. تحفظ المهمة رد المساعد وترسل أحداث البدء أو الاكتمال أو الفشل إلى كل اتصالات المحادثة المفتوحة، وتحرر الحجز دائمًا.

## اتجاه الاعتماديات

```text
api/ ─► services/ ─► db/repositories/
  │          │
  │          ├─► graph.py
  │          └─► realtime/
  └─► schemas/
```

- مسارات الواجهة البرمجية رقيقة ولا تنفذ استعلامات أو معاملات مباشرة.
- أخطاء التطبيق لا تعرف بروتوكول HTTP؛ طبقة `api/` تحولها إلى حالات واستجابات.
- الرسم لا يعرف وسيلة النقل، ويستخدم مفتاح نقطة تفتيش مركبًا من المستخدم والمحادثة.
- جداول نقطة التفتيش يديرها لانغ غراف، أما جداول التطبيق فتديرها الترحيلات.

## الهوية والعزل

- الهوية العامة تعتمد `user_id` وفق القرار `ADR-0009`.
- لا يقبل مسار المحادثة معرف المستخدم من العميل؛ يستخرجه من جلسة المصادقة.
- التحقق من ملكية المحادثة مطلوب قبل تشغيل الرسم أو فتح مقبس الويب.

## الحماية التشغيلية

- مسارات التسجيل والدخول والمحادثة محكومة بمحدد معدل بنافذة منزلقة (`ADR-0011`).
- لا يبدأ التطبيق في بيئة `production` ببيانات اعتماد التطوير أو مفتاح نموذج فارغ أو أصول CORS غير آمنة.
- حالة محدد المعدل واتصالات المقبس وسجل التشغيلات النشطة داخل ذاكرة عملية واحدة؛ التوسع الأفقي يتطلب مخزنًا مشتركًا.

## الاستجابات والأحداث

- تستخدم استجابات HTTP غلاف نجاح أو فشل موحدًا.
- تستخدم أحداث مقبس الويب عقدًا منفصلًا يحتوي النوع والبيانات والخطأ.
- لا تُرسل تفاصيل الاستثناءات الداخلية إلى العميل.
- في وضع التصحيح (`DEBUG_METADATA`) تحمل رسالة المساعد ميتا ديتا مصدرها في عمود
  مستقل عن المحتوى، ويظهرها العميل في لوحة مطوية تحت الرد (`ADR-0012`).
